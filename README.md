```
It is a simple sound recording and audio file handling program developed
while learning Python.
```

# `## Features` 

- `Record audio from a selected input device` 

- `Save recordings as WAV` 

- `Display recorded file size` 

- `Load existing audio files` 

- `Display audio duration` 

- `Convert audio files to FLAC` 

- `Basic error handling` 

# `## Libraries` 

- `sounddevice` 

- `soundfile` 

- `scipy` 

- `os`
